# Sleipnir desktop — 10 multi-page mockups

Open `index.html` to compare all ten directions. Each direction has six working pages: Command, Run graph, Console, Review, Routing, and Trust.

For consistent local asset loading, serve this folder:

```sh
cd /home/prahladv/Projects/sleipnir
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/design-demos/sleipnir-desktop/`.

These are selection prototypes, not production UI. Buttons that would execute work, spend money, touch credentials, or alter Git are intentionally non-operative.

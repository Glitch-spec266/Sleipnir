Budget-aware agentic orchestration

Delegate the work. Keep the context thin.

Arcaflame takes one complex project prompt, decomposes it into a task DAG, and dispatches every task to the cheapest model tier that can actually do it — while the orchestrator's own context stays flat and spend stays inside your five-hour window.

It rests on one property: delegation only saves money if subtask output never re-enters the orchestrator's context. So the plan lives on disk, and the orchestrator is re-invoked fresh each cycle with nothing but a compact, size-bounded manifest.

What it does

Everything between a prompt and a finished, paid-for plan.

Twelve of them, in the order a run meets them. No agent framework underneath any of it.

01 Plan

Prompt → validated task DAG

The planner turns one paragraph of intent into typed tasks with real dependencies, and validates the whole graph before a single token is spent.

Tier routing, with its reasoning

Every task is labelled reason, code, mechanical or extract. The router maps each tier to the cheapest model that clears it — and explain prints why it chose what it chose.

Policy you write, in TOML

A backend order per tier. The shipped example keeps Claude first for reasoning, a Codex subscription first for bulk code, and OpenRouter first for cheap mechanical work — so the tight window is spent on thinking.

02 Dispatch

Three backends, zero re-implemented auth

claude -p, codex exec and plain OpenRouter HTTP. The adapters shell out to the official CLIs and inherit their credentials. No adapter runs an OAuth flow.

Parallel work in isolated workspaces

Readiness comes from the graph, not a queue: a concurrency cap, cancellation, timeouts and tree kill. Each attempt gets its own directory, so nothing leaks sideways between tasks — and a dry run spends nothing.

Acceptance checks

Tasks carry checks that have to pass before the work counts. A task is not finished because a model said it was finished.

03 Control

Budget governor

Five-hour window accounting across providers, with automatic downshift to cheaper tiers before the wall — not an error after it. Codex subscription usage is tracked in its own pool.

Sparse brain

Costs nothing while workers succeed. At a terminal impasse it gets the bounded manifest plus at most four urgent task specs — 24k characters, hard capped — and may stop, defer, or propose a typed revision.

Audited plan revisions

Blast radius is computed locally before anything is written. Routing-only retargets can auto-apply; semantic changes wait for apply-revision. Superseded tasks and stale descendants rerun in dependency order.

Live terminal dashboard

tui shows DAG, routing and budget; --watch follows a run, --run drives one under a lock. Dependency-free, offline in read-only mode, and it never prints subagent output.

Append-only run log

results.jsonl, fsynced per record. Status is a pure fold of results over the plan, so a run resumes exactly where it stopped and no state can drift away from the log.

One OS seam, two first-class platforms

Process trees, file locking, raw console mode, shell selection, input injection and screen capture all go through one platform layer picked at import — ydotool on Linux, SendInput, GDI and job objects on Windows. No admin rights, no kernel driver, and doctor says exactly what your host will and will not allow.

The property everything rests on

The orchestrator's context does not grow with the plan.

Multiply the work by 166× and the brain reads the same page. That is the whole economic argument, and it is enforced by a test: test_manifest_size_is_constant_in_task_count fails the build if a change reintroduces growth.

Get it

Python 3.12, two dependencies, no account to create.

Arcaflame installs from source and borrows the provider CLIs you already have signed in. Nothing phones home.

Linux & macOS

git clone https://github.com/Glitch-spec266/Arcaflame
cd Arcaflame
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e .
.venv/bin/python -m pytest -q

Windows

git clone https://github.com/Glitch-spec266/Arcaflame
cd Arcaflame
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe -e .
.venv\Scripts\python.exe -m pytest -q

Then point it at a plan

sleipnir plan "ship a REST API"
sleipnir tui --orchestrate

The CLI entry point is sleipnir (alias orch) until the rename lands in the package.

Providers

The claude and codex adapters use whatever those official CLIs are already signed into. OpenRouter reads OPENROUTER_API_KEY. Browser control is opt-in: pip install -e ".[host]".

Before you run someone else's plan

CommandCheck acceptance checks execute shell commands out of plan.json. A plan file is executable content. Do not run one from a source you do not trust.
